# Homepage

The home route is `app/page.tsx`.

The header places `public/logo.png` on the left. The logo is `2.375rem` tall, and `1.625rem` on narrow screens. The file is the gold mark together with the words Studio Luce, on a black ground. The page background is the same black, so the rectangle around the logo does not show.

Under the header, the hero heading is the single line `Studio Luce: L’Anima del Vetro`. The section background is `public/hero-applique.jpg`, a wall lamp under a painted frieze, cropped toward the lower right. A black veil at 68% opacity covers the photograph so the gold title stays in front.

Below the hero, `Artigianato Senza Tempo` is a two-column block. The copy sits on the left. The right column is `public/lampada-sospensione.jpg`, a blown-glass pendant lamp. The image is taken out of the document flow and cropped with `object-fit: cover`, so the column grows with the text and the photograph matches that height. Inside the left column, a bordered box titled `Il Segreto di Murano` uses a smaller heading than the section title. On a narrow screen the columns stack, with the text first, and the photograph keeps a 4:5 frame.

The document language is Italian. The browser title is Studio Luce.
